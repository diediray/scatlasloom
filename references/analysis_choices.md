# 选列与数值

先检查实际marker。谱系信号、功能信号、应激、细胞周期及混合表达都可能解释群间差异。保持原分群编号，展示证据后再判断是否值得改变注释。对已确定的研究问题优先选预先定义的功能集；为解释当前观测整理的小面板标明为本次描述性选择。

为所选列保存 feature_registry.tsv：模块、feature、显示名、完整基因成员、出处/原文锚点、选择理由、计算/汇总/缩放定义、缺失成员。来源明确到图表或本地结果文件。热图颜色高仅表示其图例所定义的高值；列内min-max不能比较不同基因集的绝对活性，少群情况下也会放大小差异，原始均值一同交付。

表达基线可采用raw RNA总UMI归一化到CP10K后log1p。同名基因先汇总counts；缺失基因与测量为0不同。简单面板均值适合描述，不宣称是独立验证或特定算法的enrichment score。

PROGENy采用有出处的物种网络；记录top基因数量、覆盖及版本。随附MLM helper为每个细胞拟合全部网络通路和截距，得到斜率t值，再按群平均。通路z-score按通路跨群计算。MLM的t值是活动评分，不能解释为患者间显著性。参考：[decoupler官方示例](https://decoupler.scverse.org/en/v1.9.2/notebooks/progeny.html)。

条件比较先定义分母（例如患者条件内所有保留成纤维细胞）、病例单位及配对关系。配对数据可以画患者内比例差的均值，以患者级置换/配对检验评估差异；这种效应写百分比点差，不写OR。未配对、复杂分层或重复区域样本需依实际设计建模。技术重复可在同一生物样本内合并；区域若是匹配设计的一部分，应先在同患者同区域比较，再把区域差值汇总到患者，或明确使用相应分层模型。含0计数的群仍进入组成表，不能遗漏。


少量细胞的患者组成不稳定时做明示的敏感性分析并保留全样本结果。未通过多重校正仍可展示效应和不确定性，图中文字如实解读。没有患者映射时采用描述性组成或表达模块。
