# Changelog

## [0.1.0] — 2026-10-11

Initial public release of **scAtlasLoom**.

### Added

- Codex workflow with explicit user review of clustering and annotation before downstream analysis and final figure production.
- Paired population-highlight and marker-evidence layout, with separate support for parent–subtype hierarchies.
- R helpers for marker preparation, modular rendering, and selected numerical summaries.
- Configurable expression heatmaps, violin panels, and biological-replicate points in the compact renderer.
- Reproducible synthetic example and PNG, PDF, SVG exports.
- English and Chinese project guides, input contracts, source attribution, and validation notes.

### Current scope

- Compact renderer: 2–9 groups; at most six selected marker rows per group.
- Scientific instructions and detailed references are primarily in Chinese.
- The R scripts rely on the agent workflow and user to enforce scientific approval.
