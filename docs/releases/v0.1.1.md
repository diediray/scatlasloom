# scAtlasLoom v0.1.1

**A denser hierarchy gallery, closer to the visual rhythm of a full atlas.**

首页展示更新为更紧凑的层级图谱：80,000 个合成点、五个父类、28 个亚群，配有 marker 点图与两组连续热图。

## Preview

![Synthetic hierarchy atlas](https://raw.githubusercontent.com/diediray/scatlasloom/v0.1.1/examples/hierarchy_preview.png)

*All coordinates, memberships, and values are synthetic. This is a rendering demonstration, not a computed biological UMAP or an annotation result.*

## What's changed

- Added a reproducible hierarchy example with 28 aligned rows, 168 marker bubbles, and 392 heatmap cells.
- Updated the English and Chinese homepages to feature the hierarchy example.
- Added optional row, group, sidebar, and legend spacing settings to the hierarchy renderer, plus a web-preview export. Existing defaults remain unchanged.
- Retained the compact six-group example and documented both reproduction commands.
- Preserved the requirement for user approval of real-data clustering and annotation before downstream analysis and final figure production.

## Install

```bash
git clone https://github.com/diediray/scatlasloom.git ~/.codex/skills/single-cell-subtype-atlas
```

Invoke **`$single-cell-subtype-atlas`**. Alternatively, extract `scatlasloom-v0.1.1.zip` and place its `single-cell-subtype-atlas` folder in your skills directory.

## Reproduce this figure

```bash
Rscript examples/make_hierarchy_demo.R
Rscript scripts/render_atlas.R examples/generated/hierarchy/config.R
```

See the [example guide](https://github.com/diediray/scatlasloom/blob/v0.1.1/examples/README.md) for dependencies and both layouts.

## Validation

Rendered PNG, PDF, SVG, and a web preview on macOS. Verified all 80,000 unique point IDs, 28 aligned rows, five parent memberships, and complete cluster–feature keys. The legacy default configuration also passes input validation. This checks rendering and structure, not biological accuracy.
