# scAtlasLoom v0.1.0

**Single-cell evidence, woven into a coherent atlas.**

首个公开版本：将主 UMAP、逐群高亮、marker 证据与按研究问题设计的扩展模块组织为完整图谱。

## Highlights

- Paired population highlights and marker evidence with coordinated colors and aligned rows.
- Support for single-lineage subtype figures and a separate parent–subtype rendering contract.
- Configurable expression heatmaps, violins, and biological-replicate points.
- Explicit user review of clustering and annotation before downstream analysis and final figure production.
- English/Chinese guides and a fully synthetic rendering example.

## Install

```bash
git clone https://github.com/diediray/scatlasloom.git ~/.codex/skills/single-cell-subtype-atlas
```

Invoke **`$single-cell-subtype-atlas`** in Codex. For a pinned download, extract `scatlasloom-v0.1.0.zip` and place its `single-cell-subtype-atlas` folder in your configured skills directory.

## Validation and scope

The synthetic example was run locally on macOS and produced PNG, PDF, and SVG outputs. R source parsing, skill metadata validation, and local documentation links were checked. These checks do not establish annotation accuracy or cross-platform rendering equivalence.

The compact renderer currently supports 2–9 groups and up to six selected markers per group; larger hierarchies use a separate contract or require adaptation. The detailed scientific workflow is primarily in Chinese. Scripts do not independently enforce the human approval gate.
