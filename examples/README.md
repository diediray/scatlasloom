# Reproduce the examples

Both examples use generated coordinates and artificial values. They demonstrate layout and numerical encodings only; neither computes a UMAP or infers biological identities.

Install `ragg`, `svglite`, and `systemfonts`; the default font is Arial. Run commands from the repository root.

## Hierarchy gallery — homepage figure

```bash
Rscript examples/make_hierarchy_demo.R
Rscript scripts/render_atlas.R examples/generated/hierarchy/config.R
```

The fixed seed generates 80,000 points, 28 subtypes, and five abstract parent groups. Each subtype row aligns marker bubbles with two continuous heatmaps (six and eight columns). Output is in `examples/generated/hierarchy/output/`, including a 450 dpi PNG, PDF, SVG, and 180 dpi web preview.

M1–M6, P1–P6, and S1–S8 are artificial feature identifiers, not genes or measured biological programs. Color represents simulated z-scores; marker area represents simulated detection percentage. Parent groups A–E do not imply biological annotations.

## Compact six-group example

```bash
Rscript examples/make_synthetic_job.R
Rscript scripts/render_modular_atlas.R examples/generated/figure_job.rds examples/generated synthetic_atlas
```

Outputs are written to `examples/generated/`. This example illustrates the per-group marker layout with optional heatmap and violin panels. Its 600 dpi PNG and PDF/SVG exports remain available through the commands above.

Generated inputs, session reports, and large outputs are ignored by Git. The committed preview images are generated by the corresponding renderers.
